# Угадай число

![ci](https://github.com/legendary-java-tutorial/course2026-gh42-game/actions/workflows/ci.yml/badge.svg) ![Node.js 24.12+](https://img.shields.io/badge/Node.js-24.12%2B-339933) ![license MIT](https://img.shields.io/badge/license-MIT-blue)

Игра в терминале: компьютер загадывает число, вы угадываете по подсказкам «больше» и «меньше».

Тема: Числа — угадывайте числа от 1 до 100.

## Режимы

| Режим | Диапазон |
|---|---|
| classic | 1–100 |

## Как играть

`npm start` — и угадывайте. Тесты — `npm test`, на каждом PR их запускает робот ci.
